# 镜生 H3

原生 macOS 本地视频生成工作台，使用 SwiftUI 与 AppKit。固定名称为「镜生 H3」，Bundle ID 为 `com.wengong.WanshenjiH3Studio`，正式入口为 `~/Applications/镜生 H3.app`。当前源码版本为 **0.4.17（23）**；源码版本不代表已经安装或完成真实生成。

S05 阶段导入 v2 分别绑定河谷和闭目首图，保留原片土石切点及第四段的已验收末帧依赖；睁眼图只作为动作参考。相同阶段导入保持绑定身份，输入修订不会恢复已取消任务或解除队列暂停。

0.4.17 为已拒绝且输入检查通过的候选提供“人脸保真对照”：分别运行 768×448 与 1536×896 的静态片 VAE 编解码（同一图片重复34帧输入，输出22帧），再按需生成 22 帧高细节短段。高细节输入直接来自完整原图，原种子、提示词和步数保留。每次实验占用同一 GPU 互斥，记录实际输入、管线、原生输出、报告与画面结论的指纹；相同输入的同一实验不自动重试。实验和原候选分别保留，不增加视频分段，不自动通过人脸检查或授权续段。提高分辨率并不保证身份保持，必须查看实际像素及动作。 对照结论区分编解码、人脸信息不足、运动身份漂移和动作错误，并在结果页明确显示应用可处理的部分、下一步与所需素材；第26镜提供分别用于参考图重绘和接触/回弹动作修订的可复制Prompt，复制不会改动冻结输入。

## 工作流

完整静态图或实际源帧绑定 → App 复制原图并完整缩放补边 → 输入图片与提示词检查 → App 冻结输入 → 单 GPU 生成 → 完整音视频技术检查 → 人工候选接受或重做。

- 镜头数、完整图库图片数、当前视频分段数分别统计；旧任务与重做记录另行保留。
- 待验收只阻塞依赖该候选的续段，独立且准备完成的任务仍可串行执行。显式暂停和取消阻止后续启动；重新打开 App 保持暂停。
- App 内接受即记录当前候选、原生端帧、动作修订和续段关系，无需聊天二次确认。技术检查通过与画面接受分别记录。
- “导入输入图审…”校验实际图片、提示词、任务与修订指纹，归档图审文件，并尊重队列暂停。输入图审不会接受生成视频。
- 接受来源补录导致回执 SHA 改变时，“恢复本段”仅适用于未投递、无生成尝试、原图审通过且内容完全相同的续段。原失败、旧回执、提案、准备与图审均归档；输出、端帧、参数或授权变化仍拒绝恢复。
- 当前执行和下一项使用同一调度判断。短后台轮询保留已核验显示；只有实际生成时边框动画运行。结果页保留“查看重做任务”及返回导航。
- 原始 H3 候选单独保存，未经画面验收不会选入 MV。合入 MV 须保留原歌曲、移除候选自带声音，并记录独立后处理；技术通过不代表已经合入。

## 构建、验证与安装

需要 Apple Silicon Mac、macOS 14 或以上以及 Xcode Swift 编译器。本机使用 Xcode 27 / Swift 6.4。源码和正式工作区彼此独立，搬迁后先检查外部路径，不重新下载模型。

```sh
zsh scripts/build.sh
zsh scripts/verify.sh
zsh scripts/install-user.sh --plan
zsh scripts/install-user.sh --install
```

构建输出为 `build/release/镜生 H3.app`，使用固定的本机证书签名。缺少身份时停止构建，不能回退临时签名；首次配置和迁移见 [SIGNING.md](SIGNING.md)。模块缓存按源码目录隔离，避免搬迁后复用绑定旧目录的 Swift 缓存。验证脚本顺序运行独立 CPU 合成测试，将结果绑定到同一源码摘要和已签名程序 SHA；不会调用真实 H3。

安装器校验候选签名和程序文件，通过工作区与实例锁拒绝运行中替换，原子更新固定正式入口。旧版本保存为逐文件解压回读验证过的压缩包。安装不会启动 App 或修改正式任务记录；已有标准工作区优先使用。

支持单项回归，例如：

```sh
zsh scripts/verify.sh receipt-rebind ready-frontier first-shot
```

部分集成测试只读核对已存在的本机交接清单、素材和外部运行时；仓库不包含这些资产。测试条件缺失必须明确报告，不能视作已完成真实生成或界面验证。
